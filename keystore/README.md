# Ключ подписи

`echidna-release.jks` — ключ, которым подписываются релизные сборки из CI.

Зачем он лежит в репозитории: без постоянного ключа каждый запуск CI создаёт новую отладочную
подпись, и новая версия приложения не ставится поверх предыдущей («Приложение не установлено»).
С этим файлом все сборки подписаны одним ключом, поэтому обновления ставятся обычным способом.

Пароли (это домашний проект, ключ нужен только для того, чтобы обновления ставились поверх):

| что | значение |
| --- | --- |
| файл | `keystore/echidna-release.jks` |
| пароль хранилища | `echidna-studio` |
| псевдоним | `echidna` |
| пароль ключа | `echidna-studio` |

Если в настройках репозитория появятся секреты `ANDROID_KEYSTORE_B64`,
`ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`, CI возьмёт ключ оттуда, а
не из этого каталога.
